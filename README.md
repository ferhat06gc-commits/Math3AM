# الرياضيات — السنة الثالثة من التعليم المتوسط

تطبيق تفاعلي لتعلّم رياضيات السنة الثالثة متوسط، مبنيّ على الكتاب المدرسي (منشورات الشهاب):
دروس، تمارين مولّدة مع التصحيح، اختبارات، إنشاءات هندسية متحرّكة، ويعمل دون اتصال بعد أوّل فتح.

*Application interactive de mathématiques pour la 3e année moyenne (Algérie), fondée sur le manuel scolaire.*

**تصميم التطبيق وتطويره:** مهندس دكتور في الهندسة المدنية.
